# OutcomeHub v0.1.1

This release adds a **native Windows x86_64 core deployment**. The new `outcome-hub-windows-x86_64.zip` is built by Bazel on Windows and contains `outcome-hub.exe` plus a short setup guide. CI starts the packaged executable, serves the workspace over loopback, issues an operator link and checks private state-directory access controls. Linux packages continue to be built for x86_64.

The Windows executable provides core identities, groups, messages, goals and host-reviewed outcomes through its separate embedded local store. Optional external execution, sandbox, research and knowledge services are not yet available in the Windows package. Their default entries are disabled and external socket connections fail explicitly. No execution result is inferred from configuration alone.

Download the archive and `SHA256SUMS` from this release, verify the archive, and follow the [Windows guide](https://coolplayagent.github.io/agent-research-lab/docs/en/guide/10-windows.html) or [中文指南](https://coolplayagent.github.io/agent-research-lab/docs/zh-CN/guide/10-windows.html). The default Windows state directory is `%LOCALAPPDATA%\OutcomeHub\state`. Keep the operator link and state private; back up the state before upgrading.

The release assets are built from the `v0.1.1` source tag. `SHA256SUMS` records their bytes.
