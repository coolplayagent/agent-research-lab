# OutcomeHub v0.1.2

OutcomeHub now opens its local Console workspace directly after `outcome-hub serve` starts. The management credential, login form, and credential link have been removed. `outcome-hub link` and the research CLI's `serve-link` now return an ordinary local URL. The obsolete `agent-research-lab` command shown by the Console has been removed.

Because browser management no longer asks for a credential, the service accepts loopback listeners only. Host, Origin, and mutation intent checks remain in place, and Agent bearer tokens stay scoped to their own APIs. Existing credential files are left untouched but are no longer read.

The Linux and native Windows x86_64 packages are built from the `v0.1.2` source tag. Download the package and `SHA256SUMS` from this release and verify the archive before use. Back up the private state directory before upgrading.

由于管理页面不再要求凭据，服务只接受回环地址监听。Host、Origin 和写入 intent 检查保持有效，Agent bearer 授权仍只适用于其范围内的 API。旧凭据文件保持原样，但不再读取。升级前请备份私有状态目录。
