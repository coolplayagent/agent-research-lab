# OutcomeHub v0.1.0

First public release of OutcomeHub, an outcome-based multi-agent work system. This release includes the self-hosted collaboration workspace, CLI, optional execution and research services, and bilingual documentation.

## Download

The four archives are built with Bazel `-c opt` for **Linux x86_64**. Choose the core workspace (`outcome-hub-core`), optional service adapters (`outcome-hub-adapters`), full research distribution (`outcome-hub-full`), or offline migration utility (`outcome-hub-migration`). Verify a downloaded file with `sha256sum -c SHA256SUMS` after downloading the checksum file and the selected archive into the same directory.

## Get started

See the [quick start](https://coolplayagent.github.io/agent-research-lab/docs/en/guide/01-quick-start.html) or [中文快速开始](https://coolplayagent.github.io/agent-research-lab/docs/zh-CN/guide/01-quick-start.html). The documentation site is static; the workspace is self-hosted and issues a private operator link. Core collaboration starts without research or SuperPOD configuration. Keep credentials, private access links and local state outside Git.

## What is included

- Shared goals, messaging, groups, execution attempts and host-reviewed outcome versions.
- Evidence and lineage linked to external knowledge repositories, with optional research and delivery adapters.
- Replaceable agent and sandbox services using versioned protocols.
- English and Chinese guides and design documentation on [GitHub Pages](https://coolplayagent.github.io/agent-research-lab/).

The release is bound to the `v0.1.0` source tag. `SHA256SUMS` records the bytes of the published archives.
