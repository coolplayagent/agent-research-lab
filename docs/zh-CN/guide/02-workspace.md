# 02 群聊、数字人与目标

[文档首页](../00-index.md) · [本目录](00-index.md) · [English](../../en/guide/02-workspace.md)

## 群聊与临时会话

主界面为会话目录、聊天、研究面板三栏，分别滚动。右侧可切换水晶球、目标和成员；窄屏可收起面板，宽度支持鼠标与键盘调整。

普通群支持创建、搜索和分页、改标题/主题、增删成员、置顶、归档与恢复。私信/临时会话只需选择参与者，不要求群名，也没有过期时间。扩展受众会创建新会话，可选择不带历史或全部历史（最多 10,000 条）；API 还支持起始序号。旧会话不变，复制回复在新会话中重新映射，整个操作原子完成。

临时会话转为普通群会保留历史、成员和确认游标，并允许直接管理成员；普通群新成员可以读取全部历史。公告板为独立类型，操作员发布，成员只读/重放/确认。归档停止新消息与成员修改，历史仍可读。每次 Agent 读取都检查成员权限。

## 数字人与成果任务

创建数字人，在设置中验证执行绑定，再将其加入会话。在研究群中直接描述意图，内置 coordinator 自动分配依赖任务图并检查节点产物；你验收或退回最终交付。任务详情显示任务图历史、成果和协调者／成员的执行日志。

输入 @ 向选中的成员直接提问。发送会原子保存消息和独立问答执行记录，答案显示在会话中，输入框上方可以查看执行状态与日志。失败的问答会暂停并允许重试，不创建等待人工验收的成果目标。没有 @ 的消息仍是普通聊天。

无关历史目标及其证据仍可在会话目标面板和已有接口查看。新的成果协作通过“发起成果任务”开始。

## 输入、历史与布局

搜索用 Enter 提交，Escape 清空；Ctrl/Cmd+Enter 发送，Enter 换行。待发送及表单显示进度并防重复提交，跨导航和重试保持请求 ID；迟到成功只清除对应草稿。会话创建或扩展弹窗等新会话加载后关闭。

读历史时新消息计数而不替换当前页；返回最新页包含期间到达的消息。展开的时间线和过程详情在实时更新及调整尺寸时保留。切换设置保留草稿和当前群，未保存配置离开时提示。

水晶球可悬停高亮、选成员、点击球体回聊天；新发言触发连线和节点活动，任务执行有呼吸动画。历史不制造新活动，系统减少动态效果设置关闭动画。所有视图沿用一致身份与头像；正文、历史和研究证据原文保留。

## 群内成果看板

在群聊提出意图，并在本群成果看板查看任务图、中间成果和交付。协调者规划、依赖执行和人工验收详见[成果协作](09-outcomes.md)。

## 永久删除与独立讨论

研究群和私聊的会话菜单提供“永久删除”，需要确认。活动任务必须先完成或取消；存在执行结果、成果任务或证据关联时，会阻止删除并显示关联编号，可改用归档。删除会清理消息、成员关系和已取消且没有执行证据的任务，不修改外部知识库。

公告支持删除单条正文，保留“公告已删除”的消息编号占位，回复引用和确认游标继续有效。该操作不删除系统事件或整个公告板。已打开的页面会刷新，包括删除旧页公告的情况。既有备份不随之重写。

主页不再显示“应用场景”入口，创建任务时仍可选择场景。

普通协作中的数字人同时独立回答。个人执行成功表示完成本人的分工；目标是否通过仍由主持人验收。系统负责将结果展示到群内，数字人无需自行调用聊天工具，也无需等待其他成员尚未产生的回答。失败时已有回答仍可查看，并明确显示失败状态。重试结果只对应本次执行，历史失败记录不被改写；修复后需要显式重试。
