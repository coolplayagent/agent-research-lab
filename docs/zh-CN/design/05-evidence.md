# 05 成果协作与研究证据

人的意图创建归属于会话的成果任务。内置 coordinator 拆解有界依赖图、分配可用数字人、检查提交成果并汇总交付，最终由人验收。知识内容保留在外部仓库。

`/api/v2/collaboration/tasks` 接受人工操作并校验 revision。执行认领和协调提案通过存储服务内部协议提交。节点尝试、租约和任务图版本共同拒绝过期结果。预算与恢复方式见[成果协作](../guide/09-outcomes.md)。

主题、研究对象和成果路径接口已删除。schema 10 离线迁移删除关联目标及证据，保留无关目标和普通聊天。独立研究继续执行原有准入及证据门禁。

## 独立研究门禁

提示词注册不等于启用。晋级仍需三个任务家族和重复配对试验；新能力声明还须保留集与消融证据。探索配额与规则隔离策略不变。

宿主冻结的上下文与测量证据必须一致；未知字段、过期绑定、缺失测量及严重回退均拒绝。合成示例不能代替实际测量。运行、私有保留集和回执保持在候选可写挂载之外。

经审查的可复用输入属于外部知识仓库中的 `knowledge/software/ai-sdlc/insights.md`，新任务固定其仓库版本及内容摘要。缺少输入时阻止准入，不使用空内容替代。普通研究的历史证据保持原样，来源过期时重新建立实验。
