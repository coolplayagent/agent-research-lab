# 05 研究证据与协作元数据

[文档首页](../00-index.md) · [本节目录](00-index.md) · [English](../../en/design/05-evidence.md)

主题关联已有协作群。研究对象描述外部仓库、数字人、工具、模型、工作流、数据集或提示词。主题与对象修改使用 revision 校验，归属保持稳定。知识内容仍存放在绑定的外部知识仓库。

宿主提供 `GET /api/v1/collaboration/topics`、`GET /api/v1/collaboration/subjects` 和 `POST /api/v1/collaboration/coordination`（`manage-research` intent）。协调写入仅支持主题和研究对象。

版本演化与演进迭代的页面、HTTP API、存储协议及研究 CLI 集成已删除。系统不再启动自动迭代调度、版本同步或软件演进激活命令。schema 9 通过离线迁移删除其历史数据。

普通目标仍将每个工作结果绑定到当前尝试。研究回执保留源码、提示词、策略及必需的 SuperPOD 固定信息；工作提交不等于宿主验收。通用协作、设计评审仍是可选场景，研究执行继续使用原有准入与证据门禁。

## 独立研究门禁

提示词注册不等于启用。晋级仍需三个任务家族和重复配对试验；新能力声明还须保留集与消融证据。探索配额与规则隔离策略不变。

宿主冻结的上下文与测量证据必须一致；未知字段、过期绑定、缺失测量及严重回退均拒绝。合成示例不能代替实际测量。运行、私有保留集和回执保持在候选可写挂载之外。

经审查的可复用输入属于外部知识仓库中的 `knowledge/software/ai-sdlc/insights.md`，新任务固定其仓库版本及内容摘要。缺少输入时阻止准入，不使用空内容替代。普通研究的历史证据保持原样，来源过期时重新建立实验。
