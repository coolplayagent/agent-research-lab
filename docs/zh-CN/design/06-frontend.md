# 06 前端模块、共享契约与国际化

## 模块与构建

浏览器逻辑使用 TypeScript ES 模块。IM 分离 API、导航、目录、创建、成员、消息、身份和应用；研究界面分离观察、图、会话、人员配置、布局和谱系。研究 API 投影保留动态类型，IM 使用严格契约，无跨应用 JavaScript 全局变量。会话创建不包含模型执行细节。

Node 22.22.1 与 TypeScript 5.9.3 经 Bazel 固定，提交的 `dist/` 供 Rust 嵌入与 Cargo 检查，Bazel 验证编译一致性。生成命令见[开发指南](../guide/08-development.md)。

## 状态契约与服务端边界

状态域只在 `crates/contracts` 定义，生成 `web/shared/src/contracts.ts`，两个界面共用 `/assets/shared/contracts.js`。保持已有 wire value，不同生命周期使用独立命名枚举；未知 workflow 状态不能满足完成或验收门禁。

场景描述返回场景/字段 ID 和允许值，健康返回 `ScenarioStatus`，系统通知为 `{code, parameters}`。任务审计事件由宿主写入 `GoalEventKind`、目标 ID/标题和可选成员/尝试；worker 不能伪造。SQLite schema 4 增加可空事件元数据，保留旧文本及重放游标。研究结果摘要可带 `ResearchResult` code，实际报告保持用户数据。

## 语言资源

三个前端 `src/locales/` 目录保存展示文案。目前界面发布语言是 `zh-CN`；共享 translator 实现回退、查 key 和参数插值。新增语言须先有 catalog，文档提供英文不表示界面已支持英文。组件使用 key，不内嵌中文；不按文本匹配翻译用户消息、名称、指令和证据。服务端诊断与自有提示词使用英文。

Bazel 检查生成资产、语言 key、参数、状态标签覆盖和边界。约束来自 `AGENTS.md`，绑定来源的 `rust-no-chinese` 规则覆盖全部 Rust 文件；类型检查与状态机评审补充这些有界扫描。

## 界面与交互状态

目录、聊天、研究面板独立滚动；研究 Tab 为水晶球、版本、目标和成员。设置分为服务、适配器、绑定、存储和状态。响应式卡片、可滚动表单和可达提交按钮适配短屏；手机导航与研究抽屉互斥。

待处理表单禁止重复提交，请求 ID 跨重试和导航保留；迟到响应不能覆盖新选择或清除其他草稿。读历史时只计新消息，不替换当前页，返回最新页包含读取期间的到达消息。每个目标显示一个紧凑进度卡，重试后仍能展开历史失败；缺快照明确为未确认。

水晶球动画来自新观察消息和分工活动，不代表验收；历史消息不制造新活动，减少动态效果偏好关闭动画。用户名称、报告、指令与历史原文保持完整。
