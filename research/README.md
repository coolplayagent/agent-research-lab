# 研究积累与下一轮输入

`insights.md` 是运行器自动读取的简明研究输入。每条使用稳定 ID，保留状态、证据、版本、限制与下一实验。新任务绑定本文的远端默认分支提交和内容摘要，旧任务中的输入不会随文件编辑而变化。

完整知识、来源归档和实验记录统一保存在既有 SuperPOD。本目录保留适合公开且能指导后续工作的摘要，不复制私有资料、原始会话、主机配置或保留评测答案。

研究任务完成后，可以提出修改本目录的独立候选任务。提交者应逐条核对可公开证据，把实测、推断和假设分开，保留失败案例和竞争解释；经过评审与门禁合并后，下一轮自动读取新版本。模型输出不会直接覆盖已审核的研究输入。

新增条目应回答：学到了什么？证据对应哪个版本？什么情况下不成立？下一次怎样以有界实验区分竞争解释？有新的反例时更新原 ID 的适用边界，不只追加支持材料。
