# 研究输入 / Research inputs

`insights.md` 是运行器自动读取的已审查研究输入，保留在原路径，不随文档目录重组迁移或翻译。每条记录使用稳定 ID，保留状态、证据、版本、限制与下一步实验。新任务绑定远端默认分支提交和内容摘要，编辑不会改变旧任务已冻结的输入。

完整知识、来源归档和实验记录归属既有 SuperPOD。本目录只保存可公开的简明摘要，不复制私有资料、原始会话、机器配置或保留集答案。研究完成后可提出独立候选修改；核对公开证据、区分实测/推断/假设、保留反例和竞争解释，经评审与门禁合并后才供新任务读取。模型输出不直接覆盖已审查输入。新反例应更新原 ID 的适用边界。

`insights.md` is the reviewed runtime input and retains its path and contents during documentation reorganization. Stable IDs preserve status, evidence, version, limits and next experiments. New tasks pin its remote-default-branch commit and content digest; edits do not change frozen historical inputs.

Complete knowledge, source archives and experiments belong in the existing SuperPOD repository. Only shareable summaries live here, without private material, raw sessions, machine configuration or holdout answers. Propose input changes as separate reviewed candidates: distinguish measurements, inferences and hypotheses; retain counterexamples and competing explanations. Only merged, gated changes feed new tasks. Model output never directly overwrites reviewed inputs, and new counterexamples should revise the original ID's applicability.
